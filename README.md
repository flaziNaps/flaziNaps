## 🧪 Experiments from My Lab

**`01` — Building My Own Tiny KV Store**

What happens when you stop using a database and start wondering how one actually works?

My C++20 experiment starts with `SET` and `GET`, with bigger questions waiting around the corner: memory, storage, performance and architecture.

**`02` — Making Geo Models Less Painful**

Different programming languages. Different dependencies. Different ways of running things.

I'm exploring how to turn geographical models into more consistent, reproducible and manageable workloads using Java, Spring Boot and Docker.

**`03` — Giving AI Agents a Team Meeting**

Codex, Claude Code, supervisors, workers, reviewers...
